# Unslopy mark

[`unslopy-mark.svg`](unslopy-mark.svg) is an original vector mark authored for Unslopy. A warm terracotta document contains a transparent U-shaped cutout and a lighter folded corner. It uses no font glyphs, external resources, or third-party logo assets.

The mark has a 32 × 32 view box and appears at 32 pixels beside the sign-in wordmark. The same asset is the SVG favicon. The colors are `#C47C61` and `#E5AD92`; the cutout shows the surrounding background.

When the mark appears beside the product name, use an empty image alt attribute so the name is announced once. When the mark stands alone as a link, give that link an accessible name.

## Google sign-in icon

[`google-g.png`](google-g.png) is the unmodified [official Google G asset](https://developers.google.com/static/identity/images/g-logo.png) linked by the [Google sign-in branding guidelines](https://developers.google.com/identity/branding-guidelines). It appears only beside **Continue with Google**, with its original colors and aspect ratio. Its empty alt attribute avoids repeating the button label. Google owns this mark.
