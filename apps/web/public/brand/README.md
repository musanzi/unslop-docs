# unslop-docs mark

[`unslop-docs-mark.svg`](unslop-docs-mark.svg) is an original vector mark authored for unslop-docs. A warm terracotta document contains a transparent U-shaped cutout and a lighter folded corner. It uses no font glyphs, external resources, or third-party logo assets.

The mark has a 32 × 32 view box and appears at 32 pixels beside the homepage and sign-in wordmark. The same asset is the SVG favicon. The colors are `#C47C61` and `#E5AD92`; the cutout shows the surrounding background.

When the mark appears beside the product name, use an empty image alt attribute so the name is announced once. When the mark stands alone as a link, give that link an accessible name.
