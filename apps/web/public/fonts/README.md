# Web font

All web interface text uses the self-hosted Inter 4.1 upright variable font. Document content and exported DOCX fonts are unchanged.

The unmodified [publisher distribution](https://github.com/rsms/inter/blob/e3a3d4c57d5ecc01453a575621882a384c1995a3/docs/font-files/InterVariable.woff2) is bundled with its [SIL Open Font License 1.1](inter/OFL.txt). Font faces are declared in `apps/web/src/styles/base/fonts.css`, with `font-display: swap`. No external font service is needed.
