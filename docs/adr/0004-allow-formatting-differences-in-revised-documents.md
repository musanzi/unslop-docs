# Allow formatting differences in revised documents

Strict formatting preservation rejects common Word documents and prevents users from downloading otherwise usable revisions. Match the uploaded document's formatting as closely as practical, but do not reject an upload or revised document solely because exact formatting cannot be preserved. Users review and adjust the downloaded DOCX outside the app, accepting some formatting differences in exchange for broader document support.

This decision supersedes the exact-formatting requirements in the original product specification and tickets #5 and #7. Length, security, file-readability, and English/French limits remain. If a rewritten passage fails checks for quotations, citations, numbers, or references, keep the original passage and complete the rest of the document with a notice. This decision does not claim that support is already implemented.

Convert ordinary content controls into visible text or images, and use the final version of tracked changes. Preserve complex elements unchanged where possible, subject to security checks, and tell users which elements could not be edited. Retain the original download so users can recover the original controls and revision history.
