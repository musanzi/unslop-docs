# Triage labels

Each role uses a GitHub label with the same name.

| Role and label | Meaning |
| --- | --- |
| `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | The reporter needs to provide more information. |
| `ready-for-agent` | The issue is specified and ready for an agent to implement. |
| `ready-for-human` | The issue requires human implementation. |
| `wontfix` | The maintainer has decided not to implement the issue. |
